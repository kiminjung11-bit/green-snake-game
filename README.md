# 🐍 Green Snake Game

HTML, CSS, JavaScript만으로 만든 스네이크 게임입니다. 별도의 설치나 빌드 없이 브라우저에서 바로 실행됩니다.

## 실행 방법

1. 이 저장소를 내려받습니다.
2. `index.html` 파일을 브라우저에서 엽니다.
3. **게임 시작** 버튼을 누릅니다.

## 조작법

| 키 | 동작 |
| --- | --- |
| ↑ ↓ ← → | 뱀 이동 방향 변경 |

## 게임 규칙

- 400x400 캔버스, 20x20 격자 위에서 진행됩니다.
- 사과를 먹으면 뱀이 길어지고 **+10점**을 얻습니다.
- 벽이나 자기 몸에 부딪히면 게임 오버입니다.
- 최고 점수는 브라우저 LocalStorage에 저장되어 새로고침해도 유지됩니다.

## 기능

- **난이도 선택**: 쉬움(200ms), 보통(150ms, 기본값), 어려움(100ms), 매우 어려움(50ms). 게임 중에는 바꿀 수 없습니다.
- **레벨 시스템**: 50점마다 레벨업하며, 레벨이 오를 때마다 이동 간격이 10ms씩 줄어 뱀이 빨라집니다(최소 20ms).
- **일시정지**: 버튼으로 일시정지와 재개를 전환합니다.
- **소리**: 배경음악, 먹이를 먹을 때의 효과음, 죽을 때의 "띠용" 효과음이 나옵니다. 소리 파일 없이 Web Audio API로 직접 합성하며, **소리 끄기** 버튼으로 끌 수 있습니다.
- **그래픽**: 고해상도 캔버스에 비늘 무늬가 있는 뱀, 사과, 잔디 바닥을 그립니다.

## 파일 구조
